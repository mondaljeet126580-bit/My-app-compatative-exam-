ChatLink Automation

Automation ফিচারটি বর্তমানে চালু নেই। এটি প্রস্তুত ও যাচাই হওয়ার পর Admin Console থেকে নিয়ন্ত্রিতভাবে চালু করা হবে।

✓এই মুহূর্তে Automation API key তৈরি বা ব্যবহার করা যাবে না।
✓ChatLink-এর সাধারণ চ্যাট, লগইন ও মেসেজিং স্বাভাবিকভাবে চালু থাকবে।
✓ফিচারটি চালু হলে Admin Console-এর Automation API মেনু থেকে ON/OFF করা যাবে।

এটি কোনো ত্রুটি নয়। ফিচারটি প্রকাশের আগে সাময়িকভাবে নিষ্ক্রিয় রাখা হয়েছে।
