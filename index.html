How to use automation

Read profileGET ?action=profile
Read your chat listGET ?action=chats
Send a messagePOST · action=send_message

Include this header in each request:

apikey: YOUR_PUBLISHABLE_KEY
Authorization: Bearer YOUR_CHATLINK_AUTOMATION_KEY
Content-Type: application/json

JSON body for sending a message:

{
  "action": "send_message",
  "conversation_id": "CONVERSATION_ID_FROM_CHATS",
  "message": "Hello from automation"
}

Endpoint:

https://mtitrkspgoqaqdeiluud.supabase.co/functions/v1/chatlink-automation
The API key only works for your profile and chats you belong to. It cannot access other accounts, admin/maintenance settings, or control the entire Supabase database.
