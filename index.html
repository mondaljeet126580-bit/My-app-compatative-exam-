Automation API

অন্য app, script বা automation tool থেকে ChatLink চালাও

এটি আসল Automation API

Supabase-এর public key শুধু connection/gateway-এর জন্য। বাইরের automation চালাতে নিচে আলাদা ChatLink Automation Key বানাতে হবে। Key-এর পূর্ণ মান একবারই দেখানো হবে; ডেটাবেজে শুধু hash থাকবে।

Automation API বর্তমানে বন্ধ

এই User Page-এ API key তৈরি ও ব্যবহার আপাতত নিষ্ক্রিয়। ফিচারটি প্রকাশের আগে শীঘ্রই চালু হবে।

এই publishable key একা তোমার অ্যাপের নিয়ন্ত্রণ দেয় না। Automation permission নির্ধারণ করে নিচের আলাদা ChatLink key। Secret/service_role key কখনও browser-এ দেওয়া হবে না।

নতুন Automation Key তৈরি করো

যে permission দরকার শুধু সেটাই নির্বাচন করো। নিরাপত্তার জন্য Send message আলাদা করে অনুমতি দিতে হবে।

সর্বোচ্চ ১০টি active key রাখা যাবে; প্রতিটি key-তে ৬০ request/minute সীমা।

নতুন key — এখনই কপি করো

এই full token আর পরে দেখানো হবে না। নিরাপদ password manager-এ রাখো, public chat/GitHub-এ paste কোরো না।
